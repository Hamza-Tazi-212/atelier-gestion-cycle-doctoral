# GCD+ · Projet de gestion du cycle doctoral

GCD+ est le prototype de l’atelier O&M Développement Logiciel adapté au parcours doctoral de l’École Supérieure de Technologie de Fès. Il couvre la recherche de sujets, la candidature, l’inscription administrative et la réinscription annuelle.

## Parcours de démonstration

1. Ouvrir le catalogue, combiner les filtres par laboratoire et domaine, puis ajouter un sujet au panier.
2. Créer un compte candidat ou se connecter, renseigner son profil et joindre les PDF, par import ou avec la caméra. Le dépôt est limité à trois candidatures par campagne.
3. Ouvrir une candidature et consulter le bloc **Prochaine action**. Quand une pièce doit être remplacée, le lien mène au champ de dépôt.
4. Depuis un compte du personnel, ouvrir le tableau de bord affecté au compte. Suivre les décisions de sélection, contrôler les pièces administratives ou examiner une demande de réinscription selon la fonction.

GCD+ a été développé à partir d’une copie locale de CDOC. Cette documentation présente le travail réalisé pour GCD+. Le code adapté à partir de CDOC est préparé séparément pour le dépôt.
